## 학년별 학습 내용

### 1~2학년군 — 수학의 기초 체력

| 영역 | 주요 내용 |
|------|----------|
| 🔢 수와 연산 | 100까지 수, 덧셈·뺄셈 기초 |
| 📐 도형 | 입체도형, 평면도형 기초 익히기 |
| 📏 측정 | 길이 재기, 시간·시각 읽기 |
| 📊 자료 | 분류하기, 그래프 그리기 |

**Tip:** 1~2학년은 **수 감각**이 가장 중요한 시기예요. 연산 속도보다 숫자와 친해지는 게 우선입니다.

---

### 3~4학년군 — 수학이 어려워지는 분수점

| 영역 | 주요 내용 |
|------|----------|
| 🔢 수와 연산 | 곱셈·나눗셈, **분수·소수** 기초 |
| 📐 도형 | 각도, 삼각형·사각형의 성질 |
| 📏 측정 | 넓이, 들이, 무게 |
| 📊 자료 | 막대그래프, 꺾은선그래프 |

> **⚠️ 주의:** 3~4학년은 **분수**가 처음 나오는 시기예요. 여기서 개념을 제대로 잡지 못하면 고학년에서 수포자가 될 가능성이 높아집니다.

| 영역 | 주요 내용 |

| 🔢 수와 연산 | 분수·소수 혼합 계산, 약수·배수 |

**2026년 5~6학년 주요 변경점**
- 분수·소수 혼합 계산 비중 조정
- 통계 단원에서 **데이터 분석** 강화
- 실생활 문제 해결 사례 증가

## 수포자가 안 되는 방법 (초등 필수)

초등학생 **6명 중 1명**이 수포자라는 통계가 있어요. 
수포자는 보통 **초등 3~4학년, 분수에서 시작**됩니다.

### 수포자 발생 원인

| 원인 | 설명 |
|------|------|
| **분수 개념 실패** | 분수 이해 못 하면 이후 모든 수학이 어려워짐 |
| **선행 학습 스트레스** | 사교육으로 앞서 나가다 개념을 놓침 |
| **암기 위주 학습** | 원리 이해 없이 문제 풀이만 반복 |
| **수학 = 점수** 인식 | 수학을 입시 도구로만 보게 됨 |

### 수포자 예방 5가지 방법

#### 1️⃣ 분수, 초등 3학년이 골든타임
분수는 **초등 수학의 분수령**입니다. 3학년 때 분수 개념을 반드시 제대로 잡아야 해요. 분수를 그림으로 이해하고, 실생활 예시(피자, 케이크 자르기)로 접근하면 효과적입니다.

#### 2️⃣ "왜?"를 묻는 아이로 키우기
정답 맞히는 게 중요한 게 아니라, **"왜 이렇게 되는 거야?"** 라고 묻는 습관을 길러주세요. 서술형 평가에서도 과정을 설명하는 능력이 중요해졌어요.

#### 3️⃣ 매일 10분 연산 + 개념 학습
하루 10분만 꾸준히 해도 충분합니다. 중요한 건 **많이 하는 게 아니라 꾸준히** 하는 거예요.

```
[추천 루틴]
매일 10분: 연산 문제 5~10개
주 2회: 개념 학습 (원리 이해)
주 1회: 실생활 수학 (가격 비교, 요리 계량 등)
```

#### 4️⃣ 배운 내용을 설명하게 하기
"오늘 학교에서 뭐 배웠어?" 대신 **"엄마한테 오늘 배운 거 설명해줄래?"** 라고 물어보세요. 남에게 설명할 수 있어야 진짜 아는 거예요.

#### 5️⃣ 실생활 수학 경험 쌓기
수학이 실생활과 동떨어졌다고 느끼면 흥미를 잃기 쉬워요.
- 🛒 마트에서 가격 비교하기 → 자연스러운 수학
- 🍳 요리할 때 계량하기 → 분수와 단위 익히기
- 🚗 목적지까지 시간 계산 → 속력 개념 익히기
- 🏦 용돈 관리 → 돈 계산과 사칙연산
