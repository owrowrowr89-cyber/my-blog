# 테슬라 FSD 한국 8월 구독제🔥 모델3/Y HW3도 가능? v14 Lite 총정리

안녕하세요~ K잇핏입니다! 🚗

2026년 8월, 테슬라 FSD가 한국에서 **월 구독제**로 전환된다는 소식! 자세히 알려드릴게요.

---

## FSD 한국 도입 현황

테슬라는 2025년 11월 한국에 **FSD v14 Lite**를 출시했어요. 한국은 미국 다음으로 **세계에서 두 번째** FSD 출시 시장입니다.

| 구분 | 내용 |
|------|------|
| 도입일 | 2025년 11월 |
| 버전 | FSD v14 Lite |
| 지원 차종 | **미국산** 모델3·Y (HW3 이상) |
| 미지원 | 중국산(상하이) 모델3·Y |
| 국내 등록 | 약 2,134대 |
| 8월 예정 | 월 구독제 전환 |

> **중요:** 중국 상하이 공장에서 생산된 모델3/Y는 FSD가 지원되지 않아요. 미국산 모델만 가능합니다!

---

## HW3 vs HW4 차이

| 구분 | HW3 | HW4 |
|------|-----|-----|
| FSD 지원 | ✅ v14 Lite 가능 | ✅ Full FSD |
| 성능 | 제한적 | 풀 스펙 |
| 메모리 대역폭 | 낮음 (HW4의 1/8) | 높음 |
| 업그레이드 | 테슬라 지원 약속 | - |

일론 머스크는 HW3 차량의 비감독형 FSD 실행 능력이 "거의 없다"고 인정했지만, 테슬라는 **HW3 지원을 포기하지 않았다**는 입장을 계속 밝히고 있어요.
