## 1. 맥북 잠자기 중 커널패닉, 왜 발생할까?

맥북을 덮개를 닫아 잠자기 모드로 전환했는데, 다음에 열어보면 **"컴퓨터가 문제로 인해 재시동되었습니다"** 라는 메시지가 뜬 적 있나요?

이는 맥북이 잠자기 상태에서 **메모리(RAM) 전원을 잃거나**, **절전 모드 전환 과정에서 충돌**이 발생해서 커널패닉(Kernel Panic)이 일어나는 겁니다.

### 주요 원인
- **hibernatemode 설정 충돌** (가장 흔함)
- 외부 모니터 연결/해제 중 전환 문제
- USB 허브 등 주변기기 호환성
- macOS 업데이트 후 설정 꼬임

---

## 2. hibernatemode 3 vs 25 차이점

이 문제의 핵심은 `hibernatemode` 설정입니다. macOS에는 잠자기 모드가 여러 가지 있는데, 맥북의 **기본값은 3번**이에요. 이 3번 대신 **25번**으로 바꾸면 많은 커널패닉 문제가 해결됩니다.

| 항목 | 모드 3 (기본값) | 모드 25 (추천) |
|------|---------------|--------------|
| **정식 이름** | Safe Sleep (기본) | Safe Sleep (강제) |
| **RAM 유지** | ✅ 유지 | ✅ 유지 |
| **디스크 이미지** | ✅ 만듦 (조건부) | ✅ 항상 만듦 |
| **적용 조건** | 배터리/전원 상태에 따라 다름 | **무조건 safe sleep** |
| **깨어나는 속도** | 빠름 | 빠름 (RAM에서) |
| **커널패닉 위험** | 🟡 가끔 발생 | ✅ 매우 낮음 |

### 모드 3의 문제점

`hibernatemode 3`은 맥북의 기본 설정이에요. 평소에는 RAM만 유지하다가, 배터리가 임계치 이하로 떨어지면 SSD에 이미지를 저장하는 방식입니다. 

문제는 **모드 전환 과정**에서 가끔 충돌이 일어나서 커널패닉이 발생할 수 있어요. 특히 외부 모니터 연결/해제 후 잠자기 전환 시 문제가 잘 생깁니다.

### 모드 25가 안전한 이유

`hibernatemode 25`는 **항상 Safe Sleep**을 강제하는 모드예요. RAM 전원을 유지하면서, 무조건 현재 메모리 상태를 디스크(SSD)에 저장합니다. 

- 평소에는 RAM에서 빠르게 깨어남
- 만약 배터리가 방전되거나 전원 문제가 생겨도, 디스크에 저장된 이미지로 **완전 복구 가능**
- 커널패닉 발생 확률이 현저히 낮아짐

> **단점**: 최초 잠자기 진입 시 SSD에 SleepImage를 쓰는 시간이 1~2초 추가됩니다. 그리고 SSD 수명에 대한 걱정도 있지만, 현대 SSD는 이 정도 쓰기 작업에 전혀 영향 없습니다.

## 3. 터미널로 잠자기 설정 변경하는 법

### 현재 설정 확인
```bash
pmset -g | grep hibernatemode
```

### 모드 25로 변경 (추천)
```bash
sudo pmset -a hibernatemode 25
```

### 기본값(모드 3)으로 되돌리기
```bash
sudo pmset -a hibernatemode 3
```

### 추가: auto restart 방지 (선택사항)
커널패닉 발생 시 자동 재시동을 끄면, 실제로 문제가 있을 때 확인이 쉬워요.
```bash
sudo pmset -a panicrestart 0
```

### 적용 확인
```bash
pmset -g | grep hibernatemode
```
`hibernatemode 25`가 출력되면 성공입니다.

## 4. 추가: NVRAM / SMC 초기화

터미널 설정만으로 해결되지 않는다면, **NVRAM(PRAM)과 SMC 초기화**를 해보세요.

### NVRAM 초기화 (인텔 맥)
1. 맥북을 완전히 끕니다
2. 전원 버튼을 누르고 **즉시 Option + Command + P + R** 키를 동시에 누름
3. 약 20초 후에 놓음 (또는 시동음이 두 번 들릴 때까지)

> Apple Silicon(M1/M2/M3) 맥은 NVRAM 초기화가 필요 없습니다. 그냥 재부팅하면 자동 리셋됩니다.

### SMC 초기화 (인텔 맥 with T2 칩)
1. 맥북을 끕니다
2. 내장 키보드의 **왼쪽 Control + Option + Shift**를 동시에 7초간 누름
3. 여기에 **전원 버튼**까지 추가로 7초간 누름 (총 4개의 키)
4. 모든 키를 놓고 잠시 기다린 후 전원 버튼을 눌러 켜기

> Apple Silicon 맥은 SMC 리셋 개념이 없습니다. 그냥 재부팅하면 됩니다.

## 5. 예방 팁

이 설정 외에도 아래 방법들을 함께 적용하면 더 안정적인 잠자기 환경을 만들 수 있어요.

### 자동 전원 관리 끄기
```bash
sudo pmset -a autopoweroff 0
sudo pmset -a standby 0
```

### 잠자기 전 주변기기 분리
USB 허브, 외장하드, 외부 모니터 등을 잠자기 전에 분리하면 안정성이 올라갑니다.

### macOS 최신 업데이트 유지
Apple은 매 업데이트마다 전원 관리 관련 버그를 수정합니다.

### 배터리 상태 확인
```
시스템 정보 → 전원 → 배터리 상태
```
"정상"이 아니라면 배터리 교체를 고려하세요.

## 요약

| 구분 | 권장 설정 |
|------|-----------|
| **hibernatemode** | **25** (Safe Sleep 강제) |
| **autopoweroff** | 0 (끄기) |
| **standby** | 0 (끄기) |
| **NVRAM/SMC** | 문제 있을 때 초기화 |

**맥북 기본값(hibernatemode 3)**은 배터리 상태에 따라 safe sleep을 선택적으로 사용하는데, 이 과정에서 가끔 커널패닉이 발생합니다.  
**hibernatemode 25**는 무조건 safe sleep을 강제해서 **일관된 잠자기/깨어나기 동작**을 보장합니다.

맥북 잠자기 후 깨어날 때 커널패닉 문제로 고민이라면, 지금 당장 터미널 열고 `sudo pmset -a hibernatemode 25` 한 줄만 쳐보세요. 많은 경우 해결됩니다!
